# EngineerAI Commercial Website (Preview)

This folder contains the first public-facing website foundation for EngineerAI, built with Next.js and React.

## Run locally

Requirements: Node.js 20.9 or later.

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000.

## Current scope

- Responsive marketing website.
- Student and business product positioning.
- Engineering tool overview.
- Proposed student pricing (R40/month and R400/year).
- Business plan positioning.
- Link to the existing Streamlit engineering prototype.

## Not implemented yet

This is a website preview, not a production subscription application. It does not yet include:
- User registration or login.
- Student document verification.
- Database or saved projects.
- Payment processing or subscription activation.
- Business team accounts.
- Engineering API integration.

Those features must be implemented and security-tested before collecting payments or promising paid access.

The existing Streamlit application remains separate and unchanged.
